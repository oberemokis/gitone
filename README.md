# gitone

Терминальное приложение для работы с git. Показывает, что изменилось в репозитории, и даёт посмотреть дифф прямо в консоли, без браузера и графического клиента.

## Что умеет

Дифф показывается в двух видах: split, где две колонки стоят рядом, и unified, где одна колонка и удалённые строки идут над добавленными.

Не выходя из приложения, можно поставить файл в индекс или отменить его правки, закоммитить, посмотреть лог и переключить ветку, убрать правки в stash. Дифф перечитывается сам, когда файлы в рабочей копии меняются.

Горячие клавиши, раскладка экрана, видимость элементов и тема настраиваются через JSON-файлы. Любое действие можно переназначить или отключить, кроме клавиш внутри окон: их переназначение ещё впереди. Раскладок может быть несколько: пользователь готовит свои и выбирает удобную. Встроена одна тёмная тема, её цвета меняются или пишется новая.

## На чём сделано

- Go, язык, на котором написано приложение.
- [Bubble Tea v2](https://github.com/charmbracelet/bubbletea): библиотека для интерфейса в терминале. Принимает нажатия клавиш и мыши, перерисовывает экран и подбирает цвета под возможности терминала.
- [Lip Gloss v2](https://github.com/charmbracelet/lipgloss): стили и расположение блоков на экране, то есть рамки, отступы и цвета.
- [x/ansi](https://github.com/charmbracelet/x): разбор строк с управляющими кодами терминала, например с цветами и стилями.
- [Chroma v2](https://github.com/alecthomas/chroma): подсветка синтаксиса в диффе, язык выбирается по имени файла.
- [fsnotify](https://github.com/fsnotify/fsnotify): слежение за файлами рабочей копии, чтобы дифф обновлялся без нажатия клавиши.
- git: не библиотека, а программа, которую gitone запускает и читает её вывод. Для работы нужен установленный git.

## Установка

Готовые архивы под macOS и Linux (amd64 и arm64) лежат в разделе Releases. Версия печатается командой `gitone --version`. Из исходников: `make build`, бинарник появится в `bin/gitone`. Формулы Homebrew пока нет, она появится вместе с отдельным репозиторием-tap.
