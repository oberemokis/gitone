# gitone

Терминальное приложение для работы с git. Показывает, что изменилось в репозитории, и даёт посмотреть дифф прямо в консоли, без браузера и графического клиента.

## Что умеет

Дифф показывается в двух видах: split, где две колонки стоят рядом, и unified, где одна колонка и удалённые строки идут над добавленными.

Не выходя из приложения, можно поставить файл в индекс или отменить его правки, закоммитить, посмотреть лог и переключить ветку, убрать правки в stash. Дифф перечитывается сам, когда файлы в рабочей копии меняются.

Горячие клавиши, раскладка экрана, видимость элементов и тема настраиваются через JSON-файлы. Любое действие можно переназначить или отключить, в том числе клавиши внутри окон. Раскладок может быть несколько: пользователь готовит свои и выбирает удобную. Встроена одна тёмная тема, её цвета меняются или пишется новая.

Интерфейс на английском. Язык задаётся полем `language` в `config.json`, а без него берётся из системы; новый язык добавляется словарём в репозитории, без правки кода.

## На чём сделано

- Go, язык, на котором написано приложение.
- [Bubble Tea v2](https://github.com/charmbracelet/bubbletea): библиотека для интерфейса в терминале. Принимает нажатия клавиш и мыши, перерисовывает экран и подбирает цвета под возможности терминала.
- [Lip Gloss v2](https://github.com/charmbracelet/lipgloss): стили и расположение блоков на экране, то есть рамки, отступы и цвета.
- [x/ansi](https://github.com/charmbracelet/x): разбор строк с управляющими кодами терминала, например с цветами и стилями.
- [Chroma v2](https://github.com/alecthomas/chroma): подсветка синтаксиса в диффе, язык выбирается по имени файла.
- [fsnotify](https://github.com/fsnotify/fsnotify): слежение за файлами рабочей копии, чтобы дифф обновлялся без нажатия клавиши.
- git: не библиотека, а программа, которую gitone запускает и читает её вывод. Для работы нужен установленный git.

## Установка

macOS и Linux:

```sh
curl -fsSL https://raw.githubusercontent.com/oberemokis/gitone/main/install.sh | sh
```

Windows, в PowerShell:

```powershell
irm https://raw.githubusercontent.com/oberemokis/gitone/main/install.ps1 | iex
```

Скрипт берёт последний релиз под систему и процессор, сверяет его с `checksums.txt` и кладёт в `~/.local/bin`, на Windows в `%LOCALAPPDATA%\Programs\gitone`. PATH он не меняет: если каталога там нет, скрипт напишет, что добавить. Другой каталог задаёт переменная `GITONE_INSTALL_DIR`, определённую версию `GITONE_VERSION`:

```sh
curl -fsSL https://raw.githubusercontent.com/oberemokis/gitone/main/install.sh | GITONE_VERSION=v0.4.0 sh
```

Так же делается откат на прежнюю версию. Если gitone стоит не в каталоге по умолчанию, укажите и его в `GITONE_INSTALL_DIR`, иначе появится вторая копия.

`gitone update` ставит последний релиз поверх себя. Если каталог закрыт на запись, команда подскажет запуск через `sudo`. В gitone до v0.4.0 этой команды нет, и обновляется он тем же скриптом; скрипты ставят релизы начиная с v0.4.0.

Архивы под все системы лежат в разделе Releases для ручной установки. Версия печатается командой `gitone --version`. Из исходников: `make build`, бинарник появится в `bin/gitone`; такую сборку `gitone update` не трогает, она обновляется через `git pull` и `make build`. Формулы Homebrew пока нет, она появится вместе с отдельным репозиторием-tap.
