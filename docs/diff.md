# Просмотр диффа

Дифф показывается по одному файлу, в одном из двух видов. Вид переключается на лету. Решения и отвергнутые варианты лежат в задачах эпика #2: загрузка в #7, разбор в #8, строки в #9, экран в #10.

## Что показываем

Без аргументов `gitone` показывает всё незакоммиченное: `git diff HEAD` вместе с неотслеженными файлами, они видны целиком добавленными. Переименование в рабочем дереве видно как переименование `old → new`. В репозитории без коммитов база сравнения пустое дерево, и все файлы видны добавленными.

Аргументы командной строки уходят в `git diff` как есть: `gitone --staged`, `gitone main..feature`, `gitone <коммит>`, пути после `--`. Неотслеженные файлы тогда не добавляются.

## Виды

Split. Две колонки рядом: слева старая версия, справа новая. Удалённые строки встают в пары с добавленными, которые идут за ними, поэтому правка строки стоит на одной высоте с обеих сторон. Лишние строки получают пустую половину напротив. Номера строк свои у каждой колонки.

Unified. Одна колонка: удалённые строки (`-`) над добавленными (`+`), старый и новый номер стоят рядом. Занимает меньше ширины, поэтому подходит для узкого терминала.

В обоих видах:

- добавленные и удалённые строки закрашены фоном (`diffAddedBg` и `diffRemovedBg` в теме);
- между хунками одна пустая строка, без `@@ -10,6 +10,8 @@`: скачок номеров виден и так;
- длинная строка обрезается по краю колонки, таб становится четырьмя пробелами;
- строка без перевода в конце файла получает серую пометку `No newline at end of file` на своей стороне;
- управляющие символы из файла заменяются видимыми значками, они не красят терминал и не ломают колонки.

## Выбор вида

По умолчанию `auto`: split, когда колонка диффа шире 119 колонок, иначе unified. В раскладке `focus` колонка это весь экран, в `default` она уже на ширину минус список файлов. Так же работает critique. `m` переключает от того вида, что сейчас на экране, и держит выбор до конца сеанса: смена ширины после этого вид не меняет. При переключении наверху остаётся та же строка файла.

Режим пока задан в коде. Читать его из `diff.mode` в `config.json` начнём в эпике #3.

## Особые файлы

- Бинарный файл и текстовый больше 10 МБ: строка `Binary or large file`.
- Смена прав: строка `mode 644 → 755`.
- Файл без строк (пустой, переименование без правок): строка `No content changes`.
- Блок, который разбор не узнал (`diff --cc` при конфликте слияния, вывод `--stat`): его текст как есть.

## Подсветка слов

В паре из удалённой и добавленной строки изменённые слова красятся фоном слов, ярче фона строки. Пары строк берутся по порядку внутри блока: удалённые подряд, за ними добавленные. Слово это подряд буквы, цифры и `_`, пробелы идут отдельным куском, любой другой знак отдельным токеном. Если совпала меньше половины значимых токенов, строка переписана целиком, и подсветка не ставится. Строка длиннее примерно 500 слов подсвечивается без отрезков. Решения в задаче #18.

## Клавиши

| Клавиша | Действие |
| --- | --- |
| `j`, `↓` | строка вниз |
| `k`, `↑` | строка вверх |
| `ctrl d`, `ctrl u` | полэкрана вниз и вверх |
| `g`, `G` | в начало и в конец |
| колесо мыши | по 3 строки |
| `m` | split или unified |
| `]`, `[` | следующий и предыдущий файл |
| `ctrl p` | окно поиска файла |
| `r` | перечитать дифф с теми же аргументами, что при запуске |
| `space` | файл в индекс или из индекса |
| `x` | отменить правки файла, с подтверждением `y` |

Отметка `●` перед именем в панели файлов показывает, что файл в индексе. Отменить правку можно только после `y` в подвале: любая другая клавиша отменяет вопрос. Отмена удаляет неотслеженный файл с диска, поэтому спрашивается всегда. Решения в задаче #21.

Перечитывание оставляет открытым тот же файл с той же прокруткой, обрезанной по новой длине. Если файла в диффе больше нет, открывается первый. Пока идёт загрузка, в подвале `loading`. Ошибка git остаётся в подвале красной строкой, пока не нажата следующая клавиша, а старый дифф на экране не меняется. Решения в задаче #12.

В окне поиска стрелки или `ctrl n`/`ctrl p` двигают выделение, `enter` открывает файл, `esc` закрывает окно. Всё остальное набирается в поиск, в том числе `q` и `?`.

Колесо включает режим мыши, поэтому текст в терминале выделяется с `shift`.

## Как это делится по пакетам

`git` вызывает `git diff` с нужными флагами и возвращает текст. `diff` разбирает его в файлы и хунки и строит строки обоих видов, не зная ни ширины терминала, ни цветов. `tui/diffview` раскладывает строки по ширине, красит их цветами темы и прокручивает. Корень `tui` рисует заголовок и подвал и переводит клавиши в вызовы вида.

Поэтому самую хрупкую часть, разбор и выравнивание пар в split, проверяют табличные тесты на строках, без терминала и без git.
